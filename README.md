# Minecraft Java Achievements para Bedrock

Projeto para recriar os avanços do Minecraft Java 1.16.1 no Minecraft Bedrock.

## v1.1.0

- 81 avanços do Java 1.16.1
- Progresso por jogador
- Notificações de avanço
- Menu de conquistas dentro do jogo
- Categorias: Minecraft, Nether, End, Adventure e Husbandry
- Behavior Pack + Resource Pack
- Build automática de `.mcaddon` via GitHub Actions

### Como abrir o menu

No chat do mundo, use:

`!conquistas`

ou

`!advancements`
